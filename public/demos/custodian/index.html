Custodian, in your browser

The repo's MCP server, recall sweeper and matcher start in this page, add a sample household through add_item, and check it against the CPSC, NHTSA and openFDA responses recorded in the repo's test fixtures. The repo's Preact MCP App draws each tool result on an Echo Show style screen.

  • MCP server + client in the page
  • 10 tools, 5 views
  • sweeper + MiniSearch matcher
  • recorded feeds, no outside requests
