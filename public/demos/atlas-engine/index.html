    Runs Atlas's own C++23 kernel, lab simulation and chess rules, compiled with Emscripten 6.0.9 and run single-threaded (no worker pool). The chess opponent is the committed chess_opponent.wasm, run by the browser behind this page's JavaScript stand-in for the engine's WAMR mod host, without WAMR's per-tick instruction budget. The board, map and charts are drawn by this page, not the SDL_GPU renderer; the map palettes are ported from apps/lab/view.
