Run the repo's pandas profiler on NYC Open Data

This code is the Spark profiler's test oracle. It infers each column's type from parse ratios and adds semantic types and data-quality flags. On the bundled datasets its output is checked field by field against the profile Spark committed to the repo.

Downloads Python 3.13 (Pyodide 0.29.5) with numpy and pandas: about 13 MB from cdn.jsdelivr.net, cached after the first run.
