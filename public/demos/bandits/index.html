Run the benchmark yourself

TS-GE, AdSwitch, M-UCB, UCB1 and ε-greedy from the repo run on its own benchmark cases, here, in Pyodide. Pick a case and a seed, then switch TS-GE to the Beta update as the paper prints it.

  • cumulative regret, total and decision-only
  • which arm each algorithm pulled
  • TS-GE's regret by phase
  • the paper's Beta update against the fix
  • the README's regression numbers, rerun

Downloads Python 3.13 and NumPy from cdn.jsdelivr.net, about 8 MB, cached after the first visit.
